API reference

Four endpoints do most of the work

Everything the CLI does is a documented REST call. Tokens are scoped per project, and every response includes a request id for support.

MethodEndpointDescriptionRate limit
POST/v1/branchesFork a new branch from a snapshot or a live primary. Returns connection string and TTL.60 / min
GET/v1/branches/:idBranch status, storage delta, and parent lineage.600 / min
GET/v1/branches/:id/diffSchema and row-count diff against any other branch. Destructive operations are flagged.120 / min
DELETE/v1/branches/:idReap a branch immediately. Storage is reclaimed after the 7-day undo window.60 / min

Webhooks fire on branch.ready and branch.reaped. Full reference covers 23 endpoints.
